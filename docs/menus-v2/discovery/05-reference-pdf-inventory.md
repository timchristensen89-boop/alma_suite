## 6. Distinct menu "shapes" implied for the V2 data model

1. **Tiered per-person set menu pack** (#1/#2): N tiers (name, price pp, one-line positioning blurb) × ordered course sections (section label such as TO START / CEVICHE / TACOS · TWO PER PERSON / SOMETHING SWEET) × items (name, description, dietary codes); per-section quantity rule ("two per person"); tier-level inclusions block (bottomless drinks list + duration + service rule); tier-level constraints (lunch only, 12–4pm, up to 19 guests, two hours); shared add-ons with "+$ pp" pricing (cocktail/prosecco/champagne on arrival); shared footer terms (whole-table rule, seasonal-change disclaimer, dietary legend, group-of-8 rule, surcharge, no split bills); applies to one or both venues.
2. **Functions / package document** (#3/#4, multi-page): cover; hero package with a "preferred" badge; package list (name, price pp, description, qualifier such as "WITH A SET MENU"); add-on list (+$ pp or "on request"); occasions matrix (occasion × venue → recommended packages, capacities, sitting windows, free-text perks); beverage packages as **duration-priced tiers** (2/3/4 h) with inclusions and duration-priced add-ons; weddings per-head packages; **minimum-spend table** (session × venue) with capacity notes; contact/footer block (addresses, email, surcharge).
3. **Time-boxed promotion card** (#9 happy hour; State of Origin): title; schedule as day-range × time-range pairs; price groups (category label + flat price + item list, no per-item prices); terms footer. One-off variant adds a single date and a CTA line.
4. **Fixed-price shared special** (#8 lunch special; St Alma Friday Lunch Club): price pp; included drink choice; course slots (Starter / Shared Main / Shared Side or #1/#2/#3) each holding one or more items; add-ons priced flat or pp; terms. Schedule is held elsewhere (What's On).
5. **Bottomless A5 card** (#10 and St Alma 8:11/15:11): price pp; linear course flow with "+" joins and a "Select From" choice group; add-on line; **drinks inclusions list**; conditions (2-hour sitting, whole table participates, surcharge, merchant fees, allergens).
6. **Day-specific à la carte variant** (#7 Taco Tuesday): the venue's full à la carte with a promotional section (tacos at a promo price, "every Tuesday"), item omissions, a bundle option ("Try them all 20"), and the standard Trust-our-chef tiers block. Best modelled as a derived view of the regular food menu (overrides + hidden items) rather than a separate document.
7. **What's On sheet** (both venues 28:6; allergens-menu "What's On page"): venue intro; list of recurring events (name, price tag such as "$5 / $15" or "$99 PP", schedule line, blurb); optional one-off event with a date; CTA ("Walk in, or book ahead · ALMAGROUP.COM.AU"); legend/terms. Maps 1:1 to the website's What's On items.
8. **Dessert / after-dinner A5** (Avalon 25:6; St Alma 2:9): SWEET items with prices and dietary codes; TO SIP / SIPS drinks with prices (cross-referencing the drinks list).
9. **À la carte food menu** (A4): two-column layout of sections; items with name, dietary codes, price, description; "TACOS / 9 EACH" sections with a section-level price; Trust-our-chef tiers block (boxed or strip); footer (allergen line, legend, surcharge).
10. **Drinks list / binder** (A5 portrait or landscape, 15–23 pp): cover with contents line; page types = cocktail list (name, price, ingredients, note, dietary flags N/DF), curated "favourites" lists + picks cards, essay pages with sign-off, flights (name, price, four pours), wine tables with **multiple price columns** (150 mL / 250 mL / bottle, "·" for not available) plus pairing symbols and "**" availability flag, bottle lists grouped by style, spirit lists grouped by producer with ABV, staff-pick dot and village, serving-size notes ("30 mL", "15 mL half pour"), intra-document page cross-references, page numbers, back cover.
11. **Private-event custom set menu** (to be created): an instance of shape 1 with a single tier, event metadata (host, date, venue, guest count, sitting), optional per-guest choice sections, a linked beverage package from shape 2, and the shared terms block.
12. **Beverage package** as a reusable entity: name, per-hour-tier prices, inclusions list, add-ons with per-hour-tier prices — referenced by shapes 2 and 11.
